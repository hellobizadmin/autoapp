# 사용자·도입 수요 검증 계획 및 기록지

상태: 미실시. 아래 인원·목표는 계획이며 조사 결과가 아니다. 외부 연락이나 응답 수집은 수행하지 않았다.

## 1차 인터뷰

50~60대 운전자 중 차량 경고 이해에 어려움이 있었던 사람 5~8명을 초기 탐색 대상으로 제안한다. 편의 표본의 결과를 전체 운전자로 일반화하지 않는다. 이름·차량번호·정확한 위치는 수집하지 않고 참여 동의와 익명 번호만 기록한다. 녹음은 별도 동의가 있을 때만 한다.

1. 최근 낯선 경고를 본 상황과 당시 한 행동을 설명해 주세요.
2. 무엇이 가장 이해하기 어려웠고, 어디에서 정보를 찾았나요?
3. 설명을 읽고도 판단하기 어려웠던 점이 있었나요?
4. 어떤 정보가 먼저 필요했나요? 지금 멈춰야 하는지, 위치, 다음 행동 중 실제 사례로 설명해 주세요.
5. 경고가 없을 때 조용히 감시하는 앱을 계속 켜둘 의향이 있나요? 꺼두고 싶은 이유는 무엇인가요?
6. 다음 경고에도 이 안내를 사용하겠나요? 도움이 안 된 부분을 먼저 말해 주세요.
7. 직접 비용을 낸다면 어떤 조건이어야 하나요? 무료라면 쓴다는 답과 유료 이용 의향을 구분합니다.

## 정차 상태 비교 과제

실제 운전 중 조사하지 않는다. 경고를 인위적으로 실제 차량에 발생시키지 않는다. 준비한 화면·에뮬레이터에서 동일 경고의 기존 설명 자료와 앱 안내를 비교한다. 비교 설명의 출처와 정답은 차량 취급설명서 검토 후 확정하며, 아직 정답을 검증했다고 표시하지 않는다.

- 참가자별 제시 순서를 번갈아 배치해 학습 효과를 줄인다.
- 질문: 어느 위치의 문제인가요? 얼마나 급한가요? 다음에 무엇을 하겠나요?
- 화면 이해도, 응답 시간, 글자 가독성, 다시 듣기 필요 여부를 기록한다.
- 내비 버튼을 누르지 않는 과제와 승인하는 과제를 나눠 오승인을 기록한다.
- 현재 TTS/STT 미연동 환경에서는 음성 과제 결과를 수집했다고 쓰지 않는다.

## 도입 수요 질문

차량 운영·인도·운전자 교육 담당자에게 확인할 내용이다. 아직 협력·구매 의향이 확인된 기관은 없다.

- 이용자가 차량 경고 때문에 문의하는 상황과 대응 과정은 무엇인가요?
- 현재 안내 수단으로 해결되지 않는 문제가 있나요?
- 도입을 판단하려면 어떤 정확성·책임 범위·지원 차량 근거가 필요한가요?
- 설치·운영·유지 비용을 누가 부담하며, 구매 결정을 누가 하나요?

## 결과 판정

평균만 제시하지 않고 전체 유효 표본 수, 실패 사례, 비교 조건, 응답 원문을 함께 보고한다. 이해도가 낮거나 오승인이 발생하면 문구·승인 흐름을 수정한 후 재검증한다. 안전 효과, 사고 감소, 시장 규모는 이 소규모 조사로 입증하지 않는다.
